# Schedule

Use this page as the planning view for the course. It shows the intended sequence of topics and points you to the place where timing details are published.

The current source description does not include a fixed week-by-week calendar. Use the course workspace and instructor updates for session-level dates when they are published.

## Planned sequence

1. Big data concepts, challenges, and solution patterns
2. Apache Spark architecture, RDDs, DataFrames, and Spark SQL
3. Spark SQL query tuning and performance analysis
4. MongoDB and NoSQL-based storage design
5. Integrated Spark and MongoDB pipeline project work
